# Servidor

A API do Ecobeast: NestJS + Prisma sobre o Postgres do Supabase, com Supabase Auth e Storage. O cliente Godot (`../client/`) fala só com esta API.

Ainda não há código. O servidor nasce na iniciativa `backend-api` (ver `../.specs/roadmap.md`), que define o projeto Nest, o schema do banco a partir de `../.specs/game-data/architecture.md` e as primeiras rotas do catálogo e do jogador.
